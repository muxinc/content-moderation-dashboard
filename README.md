All purpose content-moderator

# GOAL

- build a generic all-purpose content moderation tool
- Use mux robots API which has a content moderation endpoint -- the output we get back is the same as getModerationScores in @mux/ai package
- create a brand new nextjs app in a directory here -- use all the defaults
- use convex database, here's a guide for integrating convex with Mux: https://www.mux.com/docs/integrations/convex
- think and plan for what a typical content moderation workflow looks like
- this should be simple and functional
